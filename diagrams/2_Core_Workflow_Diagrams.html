Workflow 2 Autonomous Classroom Disruption & Exam Relocation Engine

Constraint Satisfaction Solver • Multi-Table ACID Transaction • Push Broadcast
➔
Stage 1: Failure Event
Room A-204 Fails
AC compressor & main projector breakdown. Room status flipped to MAINTENANCE. 60-student exam starts in 45 minutes.
➔
Stage 2: Clash Detection
Schedule Conflict Alert
System detects high-stakes Examination record for B.Sc AI & Data Science scheduled in affected room.
➔
Stage 3: Constraint Solver
Alternative Room Search
Queries PostgreSQL database for:
1. Capacity ≥ 60 seats
2. Status = AVAILABLE
3. Has Projector & AC
➔ Discovers Block B Room 101
➔
Stage 4: Atomic Execution
ACID prisma.$transaction
Atomically updates exam.roomId to B-101, marks B-101 OCCUPIED, A-204 MAINTENANCE, and writes immutable AuditLog entry.
Stage 5: Student Alert
Multicast Notification
Dispatches real-time SMS, dashboard alerts, and guidance banner to Prof. Vikram, invigilators, and all 60 students.

Workflow 3 Procurement & Separation-of-Duties (SoD) Governance

Threshold Financial Gate • Anti-Self Approval Enforced • Warehouse Inventory Lock
➔
Step 1: Shortage
Stock Drop Trigger
Industrial Circuit Breakers fall below threshold (3 remaining < 5 minStock). Technician flags during repair.
➔
Step 2: Request
Purchase Order PR-0012
Technician initiates purchase request for 10 units ($340.00). Automatically exceeds $100 auto-approval threshold.
➔
Step 3: SoD Security
Anti-Self Approval Guard
System enforces requesterId !== approverId. Requester cannot approve their own purchase (HTTP 403 blocked).
➔
Step 4: Approval
Procurement Signoff
Procurement Approver (Priya Sharma) validates supplier pricing, clicks Approve, and locks purchase order.
Step 5: Warehouse
Stock Reservation
Prisma transaction increments inventory status, updates bin Whse-A-Bay3, and appends to immutable security audit ledger.
Design Principle: Deterministic failure handling, automated human-in-the-loop escalation, and auditability at every step.
● All state transitions verified via PostgreSQL ACID transactions
